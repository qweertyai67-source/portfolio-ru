# Alexey Portfolio / RU

Одностраничное портфолио фронтенд-разработчика на русском языке.

## Структура

- `dist/index.html` — семантическая разметка страницы.
- `dist/styles.css` — адаптивная тёмная тема, светлая тема и анимации.
- `dist/app.js` — фильтрация проектов, модальные окна, мобильное меню, форма и переключатель темы.

Проект сделан без сборщика и внешних UI-зависимостей: папка `dist/` готова для статического хостинга.
